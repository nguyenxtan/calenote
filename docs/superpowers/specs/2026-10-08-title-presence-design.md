## Ownership

The bounded obligation is application-owned presence only, not a title extractor. Initially cover asserted complete exam task phrases in current USER text, excluding quotation, negation, hypothetical, question and control language. Unknown linguistic forms do not create an obligation. No general semantic parser, generated value or synthesized evidence is introduced. Semantic completeness checks coverage using model-produced title changes/alternatives and validated current-source spans, or an eligible exact retained title. Missing coverage rejects atomically as SEMANTIC_TITLE_OMITTED; no auto-fill, fuzzy matching, repair, partial persistence, extra call or oracle weakening.
