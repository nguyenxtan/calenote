## Ownership

The bounded obligation is application-owned presence only, not a title extractor. Initially cover asserted complete exam task phrases in current USER text, excluding quotation, negation, hypothetical, question and control language. Unknown linguistic forms do not create an obligation. No general semantic parser, generated value or synthesized evidence is introduced. Eligible retained CURRENT title can satisfy coverage; NEW cannot inherit another draft's title. Non-reminder queries and continuation-only turns must not be forced into CREATE.

Semantic completeness checks coverage using model-produced title changes/alternatives and validated current-source spans, or an eligible exact retained title. Missing coverage rejects atomically as SEMANTIC_TITLE_OMITTED; no auto-fill, fuzzy matching, repair, partial persistence, extra call or oracle weakening.

## Provider representation

Add an application-versioned nullable required root title-change carrier. A request-specific presence obligation makes that carrier non-null with a model-authored title SET/change, model-authored value and existing evidence pointers. Use only already-supported strict-object/scalar vocabulary, not contains/minContains/prefixItems. The carrier records its canonical change position so encode/decode preserve ordering and all values/evidence exactly. Decoder rejects duplicate title ownership, invalid positions and malformed carriers rather than resolving them. The adapter only moves explicitly generated data into canonical changes before existing evidence materialization/validators.

The base carrier remains nullable for unrelated turns. Existing non-obligated title correction/removal behavior remains possible. Request capability, schema digest, prompt digest, token measurement and actual outbound request must describe the same representation. Protocol identity advances; canonical schema authority and semantics do not change. No model output can select protocol version or expand permissions.

Wire title-presence-28 uses the carrier as the sole title SET representation on every generated request; ordinary changes retain only non-obligated title REPLACE/CLEAR. Specialization prunes unreachable definitions. Decoder refuses carrier bypass and duplicate ownership without rewriting any authored change. This generation simplification is a mitigation hypothesis for the observed nonconforming duplicate output, not proof of the provider's internal cause or of live acceptance.
