# Calenote V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish a safe V2 modular-monolith boundary, optional low-cost AI,
and a route-based personal web control plane without weakening existing channel
or persistence invariants.

**Architecture:** Retain the current vertical modules and D1 adapters while
adding contracts and a Worker composition root. New UI is built from shared
primitives and feature hooks; it talks only to same-origin Zod contracts.
Intelligence is an optional adapter returning proposals, never authoritative
writes.

**Tech Stack:** TypeScript, Zod 4, React 19, Next.js 16 static export,
Cloudflare Workers/D1/Queues, Vitest, Wrangler.

**Spec:** `docs/superpowers/specs/2026-09-08-calenote-v2-design.md`

## Global Constraints

- D1 remains canonical; migrations `0001`–`0004` are immutable.
- No production deployment, remote Cloudflare mutation, Gmail OAuth, ORM, or
  real-provider test calls.
- Preserve encrypted credentials, ownership fences, id-only queues, retry
  bounds, delivery idempotency, and the human-approval boundary.
- AI is disabled by default and never receives credentials, tokens, connect
  codes, encryption material, or browser headers.
- Use `pnpm.cmd` for local commands because PowerShell blocks `pnpm.ps1`.
- Keep Cloudflare configuration Git-reviewed, delivery credentials
  least-privilege/environment-isolated, and production delivery explicitly
  authorized. See `docs/runbooks/cloudflare-deployment.md`.
